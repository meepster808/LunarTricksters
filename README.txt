- styles.css
- Background_Blue.png, Background_Grey.png, Background_Red.png, nft1.svg, nft2.svg, nft3.svg

## Deploy
1. Create a new public repo on GitHub (or open an existing one).
2. Upload all files in this folder to the **repo root** (same level as index.html).
3. In the repo: **Settings → Pages → Build and deployment → Deploy from a branch → Branch: main / Folder: /**.
4. Open the URL shown on that Pages screen.

Filenames are case-sensitive. Make sure links in index.html match exactly.
